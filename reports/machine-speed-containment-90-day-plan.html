For the board

  1. Attackers now use AI to move in minutes. We're making our response automatic for attacks we can identify with near certainty.
  2. Automation only touches low-risk systems, is reversible in one click, and every action is logged.
  3. By day 90, 9 attack types are contained in seconds, proven by a live simulation.

Guardrails

  • 2 weeks recommend-only before any rule acts
  • Critical systems and accounts: human only
  • Rate limits and circuit breaker stop runaway automation
  • AI agent acts only after ≥ 95% agreement with analysts

How it works

Every alert takes one of three paths

Tier A: auto

workstations · standard users · human cloud roles

Tier B: contain-lite

servers (default) · execs · IT admins · workload roles → kill process, block, sign out, page

Tier C: human only

DCs · hypervisors · IdP · backup · security tools · break-glass · root

Thresholds to configure

  • Recommend period: ≥ 2 weeks per rule
  • Rule graduation: ≤ 1 FP / month, fired once, policy-listed
  • Agent graduation: 30 cases · ≥ 95% agree · 0 harmful · injection test
  • Rate limits: per rule + per action type → stop + P1
  • EDR circuit breaker: > 2% sensors silent / hour → no auto
  • Decoy breaker: > 3 hosts / 15 min → one incident
  • Decoy reads counted: shells, scripts, editors, archivers, AI agents
  • Missing tier: host or identity → B
  • Exceptions: narrowest match · owner · ≤ 12 months
  • Containment target: structured entities only, never free text
